Нужно изменить функционал ввода пользователем показаний артериального давления. Пользователь должен иметь возможность выбрать дату (по умолчанию - текущая дата), время суток (по умолчанию - текущее время суток) и поочередно ввести значения: систоличечское, диастолическое и пульс. Нужна валидация при вводе каждого из перечисленных значений. При вводе даты - нужна маска ввода даты или отображение в виде календаря. При вводе времени суток - список выбора: Утро, День, Вечер. При вводе значений: систоличечское, диастолическое и пульс - нужно чтобы отображалась цифровая клавиатура.
