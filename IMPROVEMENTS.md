**Создай интерфейс управления базой данных через CLI.**

Нужны следующие возможности (команды CLI):

- Выгрузка в csv файл всех данных из БД. Опциональо: выгрузка в csv файл данных только для укзанного пользователя и/или для указанного диапазона дат. Формат csv файла по аналогии с csv файлом, который генерируется командой `/download`, но с добавлением столбца с именем пользователя.
- Удаление всех данных из БД. Опционально: удаление данных заданного пользователя и/или для указанного дипазона дат.
- Команда, которая показывает описание формата и опций других остальных команд.

Нужно добавить алиасы для выполнения команд CLI в `Makefile`.
