# AGENTS.md

## Обзор проекта

Telegram-бот для записи и просмотра показаний артериального давления.

**`README.md` содержит:**

- Краткое описание проекта
- Ссылки на разделы в папке `readme/` (`structure.md`, `build.md`, `config.md`, `healthcheck.md`, `style.md`, `testing.md`, `ci.md`)

## Ограничения и безопасность

**Категорически нельзя без явного запроса:**

- Коммитить в обход верификации: `go build ./...` → `go vet ./...` → `gofmt -l .` → `make test` должны пройти до коммита.
- Делать коммиты, аменды и пуши без явной просьбы пользователя.
- Добавлять реальные токены и дампы БД в тесты и фикстуры.

**После внесения изменений:**

- Обновлять `README.md` с учетом внесенных изменений.
