# AGENTS.md

## Обзор проекта

Telegram-бот для записи и просмотра показаний артериального давления.

**Обязательно прочитать перед изменениями:**

- `README.md` — краткое описание проекта
- `readme/structure.md` — архитектура и поток данных (`event_consumer` → `Fetcher` → `Processor` → `doCmd` → `storage`, `notifier` в отдельной горутине)
- `readme/style.md` — ключевые конвенции кода (интерфейсы на стороне потребителя, `lib/e` для ошибок, `context.Context` сверху вниз, параметризованный SQL, язык — русский)
- `readme/testing.md` — правила тестирования
- `readme/build.md` — команды сборки и разработки, запуск через Docker, CLI для управления БД
- `readme/config.md`, `readme/healthcheck.md`, `readme/ci.md` — по необходимости

## Коммиты

- Сообщения коммитов — на русском, свободный формат без строгого шаблона.

## Ограничения и безопасность

**Категорически нельзя без явного запроса:**

- Коммитить в обход верификации: `go build ./...` → `go vet ./...` → `gofmt -l .` → `make test` → `make lint` должны пройти до коммита.
- Делать коммиты, аменды и пуши без явной просьбы пользователя.
- Добавлять реальные токены и дампы БД в тесты и фикстуры.

**После внесения изменений:**

- Обновлять `README.md` с учетом внесенных изменений.
